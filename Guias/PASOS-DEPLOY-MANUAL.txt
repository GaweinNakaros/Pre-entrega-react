PROCEDIMIENTO MANUAL (LEGACY) PARA DEPLOY A GH-PAGES
===================================================

> Este flujo es manual y se mantiene como referencia histórica. El proyecto ya no usa subcarpetas de versión (v1.3). El build se genera en `dist/` en la raíz.

PASO 1: Generar build (rama de trabajo)
--------------------------------------
1. Asegurarte de estar en la rama de trabajo:
    git checkout rama-de-trabajo
2. Instalar dependencias (si es necesario):
    npm install --legacy-peer-deps
3. Generar build:
    npm run build
4. Salida: `dist/` en la raíz del repositorio.

PASO 2: Cambiar a gh-pages
--------------------------
5. Cambiar de rama:
    git checkout gh-pages
6. Eliminar archivos antiguos (conserva .git y 404.html):
    - index.html antiguo
    - carpeta `assets/` previa
    - cualquier archivo obsoleto generado por build anterior

PASO 3: Copiar nuevo build
--------------------------
7. Volver temporalmente a rama de trabajo para copiar contenido:
    git checkout rama-de-trabajo
8. Copiar contenido de `dist/` (Ctrl+A, Ctrl+C)
9. Regresar a gh-pages:
    git checkout gh-pages
10. Pegar (Ctrl+V) el contenido copiado en la raíz.

PASO 4: Commit y push
---------------------
11. Verificar cambios:
    git status
12. Agregar todo:
    git add -A
13. Commit:
    git commit -m "deploy: build actualizado"
14. Push:
    git push origin gh-pages

PASO 5: Verificación
--------------------
15. Esperar 1-2 minutos.
16. Abrir: https://gaweinnakaros.github.io/Proyecto-React/
17. Verificar que se reflejen cambios (búsqueda catálogo, navbar con iconos, etc.).

NOTAS:
------
- No incluir `node_modules/` en gh-pages.
- Si falla la visualización de rutas internas, agregar `404.html` o configurar basename.
- Para flujos automatizados futuros considerar acción de GitHub: `peaceiris/actions-gh-pages`.
